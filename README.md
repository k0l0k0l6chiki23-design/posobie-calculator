# Калькулятор единого пособия

Статический сайт расчёта по таблицам Telegram-бота posobiebot за 2026 и 2027 годы. Данные 2027 года предварительные. Анкета обрабатывается в браузере, не сохраняется и не отправляется на сервер.

После результата доступны памятки и четыре услуги с обращением в личные сообщения MAX или WhatsApp. WhatsApp подставляет текст; для MAX предусмотрено копирование заготовки. Сообщение отправляет сам пользователь.

Для локального запуска: `python3 -m http.server 8000`. Для публикации: GitHub Pages, ветка main, корень репозитория. Без сборки и внешних зависимостей. Расчёт не гарантирует назначение пособия: имущество и иные условия проверяются отдельно.
